# Claude_Skills_GameDev
This repository holds various cluade skills for game developers.

## 스킬 세트

| 폴더 | 명령어 | 설명 |
|---|---|---|
| [fab-skills](fab-skills/) | `/fab`, `/fabfilterupdate`, `/fabupdate`, `/fabupdateforce`, `/fabuninstall` | Epic Games Fab에서 원하는 에셋을 말로 설명하면 검색 필터가 적용된 링크를 만들어 준다 |

## 빠른 설치 (Windows)

```
git clone https://github.com/kyoungwhankim/Claude_Skills_GameDev.git
```
받은 폴더를 Claude Code로 열고 `/fabinstall`을 입력하거나, `fab-skills\install.bat`을 더블클릭한다.
자세한 내용은 각 폴더의 README를 본다.
