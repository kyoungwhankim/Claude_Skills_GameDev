# Claude_Skills_GameDev
This repository holds various cluade skills for game developers.

## 스킬 세트

| 폴더 | 명령어 | 설명 |
|---|---|---|
| [fab-skills](fab-skills/) | `/fab`, `/fabfilterupdate`, `/fabupdate`, `/fabupdateforce`, `/fabuninstall` | Epic Games Fab에서 원하는 에셋을 말로 설명하면 검색 필터가 적용된 링크를 만들어 준다 |
| [ue-asset-analysis-skills](ue-asset-analysis-skills/) | `/ue-asset-analysis`, `/ueaupdate`, `/ueauninstall` | 언리얼 플러그인·프로젝트를 블루프린트·머티리얼·나이아가라 에셋 기반으로 분석해 보고서를 만든다 (UE 5.x, VS C++, Python 필요) |

## 빠른 설치 (Windows)

```
git clone https://github.com/kyoungwhankim/Claude_Skills_GameDev.git
```
받은 폴더를 Claude Code로 열고 설치 명령을 입력하거나, 각 폴더의 `install.bat`을 더블클릭한다.

| 스킬 세트 | Claude Code에서 | 직접 실행 |
|---|---|---|
| fab-skills | `/fabinstall` | `fab-skills\install.bat` |
| ue-asset-analysis-skills | `/ueainstall` | `ue-asset-analysis-skills\install.bat` |

설치 후에는 받은 폴더를 지워도 된다. 자세한 내용은 각 폴더의 README를 본다.
